PSV TAHUN 4 — UNIT 10: HARUM MEWANGI

Kandungan:
- index.html: aplikasi interaktif satu halaman untuk GitHub Pages.
- Simulator ukiran sabun dengan motif boleh diletakkan dan diseret, pilihan warna, undo, padam, kosongkan, eksport karya SVG dan skor 9 markah.
- Kuiz 21 soalan objektif, 21 markah.
- Apresiasi seni: 5 unsur seni dan 5 prinsip rekaan, 10 markah berdasarkan medan yang diisi.
- Slip pencapaian keseluruhan 40 markah: Emas (Cemerlang) 32–40, Perak (Sederhana) 22–31, Gangsa (Memuaskan) 0–21.

Cara guna GitHub Pages:
1. Extract ZIP.
2. Muat naik index.html dan README.txt ke root repository GitHub.
3. Pergi Settings > Pages.
4. Pilih Deploy from a branch, branch main, folder /(root), kemudian Save.
5. Buka URL GitHub Pages yang dipaparkan.

Aplikasi ini berjalan di pelayar dan tidak memerlukan backend atau API.
